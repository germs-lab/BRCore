# Identified core microbiome members for the switchgrass dataset

A phyloseq containing the identified core microbiome members for the
switchgrass dataset. This object is used for BRCore function examples.
It was generated by running the following on BRCore 2.0.2 (2026-04-30):

    switchgrass_core <- identify_core(
      physeq_obj     = switchgrass,
      priority_var   = "sampling_date",
      increase_value = 0.02,
      seed           = 092825
    )

## Usage

``` r
data("switchgrass_core")
```

## Format

An object class "phyloseq".

## Source

Internal test dataset.
